# /images

Cake photos live here. Drop a file in this folder, then reference it from
`designs-data.js` as `images/your-file.jpg`.

Naming: lowercase, hyphens, no spaces, `rose-ombre-tier.jpg`.
Format: JPG or WebP, roughly 1200px on the long edge, portrait crops look best
in the grid (the cards use a 4:5 ratio).

The seed cakes currently point at Unsplash URLs as placeholders, swap those
for local paths as real photos come in.
